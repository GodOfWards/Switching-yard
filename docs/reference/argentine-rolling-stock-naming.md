# Argentine rolling stock naming: reference

How Argentine railways name and number locomotives and freight cars, for naming the game's rolling stock. Researched 2026-10-08.

**Decided (Tom):**
- **The setting is Argentina** (2026-10-08). Locos, cars and naming stay within Argentine railways. Which line and era is still open.

**Status:** mostly **Secondary** (enthusiast sites, Wikipedia, OSM wiki). FA's car type codes are a gap: they're in NEFA drawings 553 and 674, which weren't read. The suggested scheme at the end is a proposal, not a fact.

## Lines (the six FA railways)

| Initials | Line | Gauge | FA number block | 1991 FEMESA letter |
|---|---|---|---|---|
| FCGR | General Roca | 1676 broad | 001–200 | A |
| FCGBM | General Bartolomé Mitre | 1676 broad | 201–400 | D |
| FCGSM | General San Martín | 1676 broad | 401–550 | B |
| FCDFS | Domingo Faustino Sarmiento | 1676 broad | 551–700 | C |
| FCGB | General Manuel Belgrano | 1000 metre | 701–900 | E (Norte), F (Sur) |
| FCGU | General Urquiza | 1435 standard | 901–999 | G |

"FC" is *Ferrocarril*. Under Ferrocarriles Argentinos (FA, 1948–1993) the cars carried the line's initials.

## Locomotives: the FA number

FA's 1960s scheme is four digits: **power digit + line block**.

| Thousands | Power |
|---|---|
| 5xxx | 600–1200 hp |
| 6xxx | 1200–1500 hp |
| 7xxx | 1500–1700 hp |
| 8xxx | 1700–2000 hp |
| 9xxx | over 2000 hp |
| 10xxx | under 600 hp |

Real examples that fit the scheme:
- **GR12W, Sarmiento: 6576–6635.** The 6 is the power digit and 576 falls in the Sarmiento block.
- **G22CW, Urquiza: 7901–7915.**
- **G22CU, Belgrano: 77xx** (for example 7744, 7763).
- **GT22CU, Belgrano: 9701–9754.**

Later prefixes:
- **The 1991 FEMESA letter** replaces the leading digit on commuter-line units: Roca **A627** was ex-6586, and Belgrano Norte **E701** was ex-7777.
- **"MF"** (for example MF701) was an unofficial Metropolitano/Materfer prefix. Those units are now F701–F705.

**EMD model letters.** G means GM export, T means turbocharged, and R means "raised", an uprated G12. The trailing letter gives the gauge: **W** is broad, **U** is metre, and no letter is standard. So the G22CW is broad-gauge and the G22CU is metre-gauge. People call locos by model ("una GR12", "la G22") or by builder ("las ALCo", "las chinas" for the CRRC units).

## Freight cars: Spanish type names

| Game type | Argentine term |
|---|---|
| Boxcar | **Vagón cubierto**; the two-axle Roca ones were nicknamed **"Carlitos"** |
| Grain hopper | **Tolva cerealera** / **granera** |
| Cement hopper | **Tolva cementera** |
| Ballast hopper | **Tolva pedrera** |
| Gondola, high side | **Vagón abierto / borde alto** |
| Low side | **Borde bajo** |
| Flatcar | **Plataforma**, also called **chata** |
| Container flat | **Portacontenedores** |
| Stock car | **Jaula** / **vagón hacienda** |
| Tank car | **Vagón tanque** / **cisterna** |
| Reefer | **Frigorífico** |
| Caboose | **Furgón de cola**; San Martín class **Z4** (corto and largo) |

Most Argentine freight cars run on two bogies (4 axles). Historic cars carried a plain number with no letter prefix, often 4 or 5 digits (for example BAGS hopper 61096, BAP stock car 45310).

**Gap:** FA's standard car type code is in the official NEFA drawings 553 ("Código numérico") and 674 ("Letras normalizadas"), hosted by CNRT. Their PDFs block automated download, so I couldn't read the actual codes. If you want the real codes, open those two PDFs from the CNRT page linked below.

## Current operators (marks for a modern setting)

| Operator | Short | Network |
|---|---|---|
| Trenes Argentinos Cargas (Belgrano Cargas y Logística) | TAC / BCyL | Belgrano, San Martín, Urquiza (state-owned; being privatised under the 2024 Ley Bases) |
| Nuevo Central Argentino | NCA | Mitre |
| Ferroexpreso Pampeano | FEPSA | Roca and Sarmiento (Rosario–Bahía Blanca) |
| Ferrosur Roca | FSR | Roca (cement, Loma Negra) |
| Trenes Argentinos Operaciones | SOFSE | Passenger services, plus shunters on metro lines |

The NCA, FEPSA and Ferrosur concessions reached their terms in 2022–23. That they still run on extensions is my inference, not checked.

## Suggested scheme for the game (retunable)

- **Locos:** use the FA number, with the power digit plus the line block, for example **GR12 6582** on the Sarmiento. For a commuter-yard flavour, use the A–G prefix instead, for example **A625**. Show the model as the class name.
- **Cars:** line initials + type name + 5-digit number, for example **FCGR · Tolva cerealera · 61204**. Number ranges per type are invented, because the real NEFA code is unread.
- **Setting:** pick one line and era. The FA era (1970s–80s) keeps the six line liveries. The modern era uses operator marks (FEPSA, NCA, TAC).
